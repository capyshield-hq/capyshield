# capyshield-reach

Lockfile and import-graph reachability for Node.js and Python.

This is an internal crate of [CapyShield](https://github.com/capyshield-hq/capyshield), a deterministic,
zero-trust egress guard and local VEX/reachability engine. Its API is not stable and may change in any
release. To use CapyShield, install the CLI instead:

```bash
cargo install capyshield --locked     # or: uvx capyshield, npx capyshield, brew, docker
```

See the [README](https://github.com/capyshield-hq/capyshield#readme) and
[how it works](https://github.com/capyshield-hq/capyshield/blob/main/docs/how-it-works.md).
